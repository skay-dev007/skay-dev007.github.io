# Swati — Portfolio

Minimal first-stage portfolio built with the Orbit Jekyll theme and hosted with GitHub Pages.

## Local preview

```sh
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

## Update content

Edit `_data/data.yml`, then run `sh scripts/check_stage1.sh` before publishing.

The original theme attribution is preserved in the site footer as required by its license.
